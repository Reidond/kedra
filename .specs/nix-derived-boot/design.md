# Derived-image VM bridge

Extend existing vm image args/request, not the VM runtime/installer authority.
Complete identity tuple invokes native_derivation::prepare then existing QEMU
tools/disk preparation over its immutable returned ID. Verify actual native
receipt/boot bytes after fixture adaptation; preserve engine/platform/provenance.
Keep ordinary images unchanged. A fixed read-only fixture observer may collect
booted deployment/kernel/initrd security facts where ordinary reads are insufficient;
never add generic guest root transport.

Current committed source composes against reviewed complete retained9d6. Native
steps select graphical.target, greetd/NetworkManager/Bluetooth, mask existing
automatic bootc timer/service, compile GLib, seed initial skeleton and generate
generic QEMU initramfs. Mutable home/user preferences are not activated here.

Qualification uses a new named private VM through public kedra-lab vm commands,
separate fixture/deployment/disk IDs, pinned controller hashes and exact owned
cleanup. Source is frozen for each build/boot; no feature-variant binary replacement.
Actual running kernel, bootloader-selected artifacts, initrd journal/drivers,
firmware/kernel trust, SELinux/AVCs and visible desktop establish the scoped gate.
