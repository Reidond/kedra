# Native stage boundary

Separate native plan/receipt/model from static schema1 composition. Closed enum
steps reuse existing assembly contracts; normalize declarations and hash parent
identity, transform implementation version, native inputs and immutable foundation
observations. Actual output hashes are separate from input identity (dracut output
may be time-dependent). Do not claim byte reproducibility without observation.

The reusable Rust model validates paths/units/modules and renders a fixed verified
recipe. The harness owns root build execution: selected immutable static image,
no pulls/network or host/device/socket binds, existing native executables only.
Accept no arbitrary RUN. Verify full RPM inventory is unchanged afterward. Final
receipt records native output hashes/modes/safe unit link targets, selected kernel/
driver checks, image and daemon IDs. Cached native images require durable binding.
Keep static verifier, profile semantics and installed trust independent.

GLib compiles the full merged schema directory. Systemd manipulates only bounded
concrete names under its native roots and records enable/default/mask links.
Initial skeleton consumes only declared committed home baselines; overlays must
not silently retain deleted baseline files or clear arbitrary skeleton entries.
QEMU initramfs uses image-local kernel versions, explicit generic/no-hostonly
generation, module containment and lsinitrd validation. Native dracut config is
shell syntax: identity-selected inputs run only inside the bounded container.
This layer consumes inherited verified dracut configuration. Changed input needs
a separate versioned native boundary; static schema1's permitted paths stay
unchanged. Never permit general /usr/lib replacement.

Cold daemon uses cached exact native Docker DinD image, private labelled data/cert
volumes and internal network, loopback mutual-TLS forwarding to inner2376,
generated fixture credentials,
no outer Docker socket/checkout/auth mounts. Add existing locked ring provider for
working TLS; no new dependency versions/tool installation. Require empty initial
image inventory and independent daemon ID. Static consumer payload streams over
API; no host path access required. Resource/disk bounds and label/nonce checks gate
cleanup; no prune/current daemon restart.

Publication faults observe real nonce image events and journal filesystem events,
SIGSTOP only directly spawned process before inspecting/terminating it. Record the
state actually captured; missed scheduling windows remain not-run. Standard
CLI/container E2E only, no permanent custom runner or production test hooks.

Parent owns Git/docs/worklog; core native model, harness execution and E2E owners
have disjoint files and frozen contracts before dependent writes/suites. Source
basis: image/assemble.sh, static context/system code, harness replay journals and
previous verified evidence. Runtime root operations remain image-local.
